## 📖 Sobre el proyecto

**BiblioRed** es el blog de una biblioteca comunitaria: un espacio donde compartir novedades literarias, reseñas, recomendaciones y un catálogo con lo más destacado, pensado para que cualquier persona pueda descubrir su próxima lectura y sumarse a la comunidad.

Este proyecto fue desarrollado como primer trabajo grupal del bootcamp de **Rolling Code School**, con el objetivo de aplicar maquetado responsive con Bootstrap, trabajo colaborativo con control de versiones y organización de tareas mediante metodologías ágiles.

## ✨ Funcionalidades

- 🏠 **Página principal** con slider de destacados y últimas entradas del blog
- 📰 **Detalle de entrada** con comentarios de la comunidad
- 🖼️ **Galería de imágenes** completamente responsive
- 🔐 **Login** con inicio de sesión social (Google / Facebook) y recuperación de contraseña
- 📩 **Suscripción** por email mediante modal
- 📍 **Contacto** con mapa y formulario
- 👥 **Acerca de nosotros** con la presentación del equipo
- 📱 **Diseño 100% responsive** (mobile / tablet / desktop)
- 🚫 Página de error 404 personalizada

## 🛠️ Tecnologías

| Tecnología  | Uso                                   |
| ----------- | ------------------------------------- |
| HTML5       | Estructura semántica del sitio        |
| CSS3        | Estilos personalizados                |
| Bootstrap 5 | Grid, componentes y responsive design |

> ⚠️ Este proyecto es solo de maquetado: no incluye JavaScript propio. Los componentes interactivos (modales, carousel, navbar) funcionan con el JS que trae Bootstrap por defecto.
